# D:\yt-video-studio — Separated YouTube Motion Engine

Built with Remotion 4, React 19, and TypeScript with strict separation of concerns (`docs/`, `config/`, `assets/`, `engine/`, `components/`, `channels/`, `tools/`, `src/`).

## Quick Commands
- `npm run dev` — Launch Remotion Studio live preview
- `npm run lint` — Run Remotion ESLint + TypeScript typecheck
- `npm run build` — Test Rspack bundle cleanly
- `npm run check` — Audit all channels, assets, safe zones, and 3s pacing rules
- `npm run sync-ep -- <epId>` — Sync `D:\Audio` `voice.wav` & `transcript.json` into channel metadata
- `npm run status` — Inspect unified `D:\Audio` + `D:\yt-video-studio` pipeline state
